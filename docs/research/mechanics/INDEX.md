# Mechanics research index

Every doc in `docs/research/mechanics/`, one row each, including docs that are planned but not written. Add or update the row whenever a doc is added or changed.

- Type: versions, system, technique or style. The style survey counts as style.
- Status: `not started` for a planned doc, `draft` once it is written, `reviewed` once Mustafa has read it. Only Mustafa sets `reviewed`.
- Confidence: High, Medium or Low, as defined in `_conventions.md`. Empty while the doc is not started.
- Reference version: the version label from `versions.md` that the doc describes.
- Open questions: how many the doc lists.
